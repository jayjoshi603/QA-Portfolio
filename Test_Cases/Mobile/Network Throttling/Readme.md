# Network Connectivity – Throttling Scenarios
This module documents manual test cases designed to evaluate mobile app performance under degraded or unstable network conditions. The objective is to validate responsiveness, error handling, and fallback mechanisms when bandwidth is restricted or disrupted

## Scope
- Application behavior under reduced bandwidth (2G, 3G, throttled Wi-Fi)
- Offline detection and fallback handling
- Synchronization errors and retry logic in unstable connections
- User interface feedback during network degradation
- Switching between network types (Wi-Fi ↔ LTE)
------------
## Out of Scope
- Battery consumption impact
- Network traffic security
- Crash recovery
