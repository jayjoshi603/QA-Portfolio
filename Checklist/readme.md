# Quality Assurance Checklists

This folder contains a curated set of QA checklists that address the core dimensions of software quality. These lists are designed to simplify manual testing, minimize the chance of missed defects, and promote consistent execution across the entire testing process.

## Objective

The aim of this section is to deliver practical, easy-to-follow checklists that can be applied:

-  During both functional and non-functional validation  
-  Ahead of release preparation or deployment activities  
-  As a quick reference guide for test planning  
-  As onboarding material for new QA professionals  

## Included Checklists

- [Functional_Checklist.md](Functional_Checklist.md) – UI interactions, input checks, navigation flows, and error management  
- [Accessibility_Checklist.md](Accessibility_Checklist.md) – screen reader support, keyboard accessibility, and color contrast compliance  
- [Performance_Checklist.md](Performance_Checklist.md) – response speed, load capacity, and energy/resource usage  
- [Localization_Checklist.md](Localization_Checklist.md) – text formatting, translations, regional conventions, and layout adaptability  

## Structure & Application

All checklists are authored in Markdown for clarity and easy accessibility in any editor. Each item is organized by category and tailored for cross-platform QA (Web & Mobile). Use them as a baseline for your test strategies or as a final validation layer before release.

 Maintain consistency, test comprehensively, and deliver with confidence.
