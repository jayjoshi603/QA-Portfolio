# SQL Queries

## Overview

This folder contains sample SQL queries used for manual data validation, functional testing, and database structure analysis.

This example aim to help QA enginners practice:
- Verifying return result via SELECT statement
- validating table relationships using JOIN
- Testing filtering, grouping, and sorting logic
- Reviewing edge cases like NULLs and missing foreign keys
