# Automation Scripting

In this section we are going to automate https://www.instagram.com website and pulling out the data from it. 

-----------

## Basic Info:
- IDE : Pycharm 2025
- Coding language : Python
- System : Windows 11 Home
- Webdriver : Geko driver

-----------

## In Scope
- Locating Url
- Login and Logout
- Locating elements using Xpath, Css Selector and name
- Sleeping time
- Adding login conditions

## Out of scope:
- Functional Testing
